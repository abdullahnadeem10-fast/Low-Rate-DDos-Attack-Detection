The report covers the extended literature review, refined research gap, proposed methodology and methodology diagram. It is a research proposal, with student roll numbers omitted from the public copy. The current experiment status is tracked in the [Phase 3 checklist](../phase%203/plan/CHECKLIST.md).

The `.tex` file is standalone: open it on Overleaf or compile with `pdflatex` twice or `tectonic --untrusted CNET_Phase2_IEEE.tex`. It uses the standard IEEEtran conference class and TikZ. The bibliography and in-paper diagram are inline. `source/build_ieee_paper.py` rebuilds the `.tex` from the reviewed content snapshot and replaces edits made directly to the `.tex` file.
